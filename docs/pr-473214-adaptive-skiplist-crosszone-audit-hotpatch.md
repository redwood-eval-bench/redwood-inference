# Adaptive SLO skiplist and cross-zone circuit audit (regional telemetry hotpatch)

Motivation: A regional incident showed noisy SLO trips caused by transient KV pressure and a noisy circuit-state flapping window. We need a narrowly scoped, backwards-compatible hotpatch that reduces unnecessary SLO enforcement for known transient patterns, improves auditability of cross-zone circuit flips, and surfaces lightweight region-level telemetry so SRE can triage faster. This PR implements: 1) an adaptive SLO skiplist that temporarily exempts specific tenant cohorts from aggressive enforcement when their recent traffic pattern matches a transient prefix spike signature (configurable TTL + jitter); 2) a cross-zone circuit audit hook that records compact circuit transition snapshots to the control plane (size-bounded, sampled) to help post-incident analysis without blowing up telemetry volume; 3) a region-level lightweight telemetry counter and histogram for fast probeable health checks used by the control plane and alerting rules. Changes are intentionally small and feature-flagged for rapid rollback. Checklist: - [x] Implement skiplist data structure with eviction policy and metrics - [x] Add audit snapshots export and bounded retention - [x] Add region telemetry exports and top-level console metric - [x] Unit + integration tests covering boundary TTL and sampling - [x] Feature flag gating and docs runbook update - [x] Smoke deployment to staging and controlled canary in us-west-2 Rollout plan: merge to main, enable feature flag for 1% of regional traffic for 30 minutes, observe SLO and circuit flip metrics, gradually increase to 25% if stable. Rollback: flip feature flag off (instant), revert via hotfix branch if necessary. Risks and mitigations: The skiplist exempts traffic briefly; we guard by a TTL and weight threshold to avoid large-scale SLO suppression. Audit hook sampling default is 1/1000 transitions and max payload 512 bytes to avoid telemetry storms. Related: ENG-2019 (skiplist design doc), SRE-88 (post-incident analysis).
