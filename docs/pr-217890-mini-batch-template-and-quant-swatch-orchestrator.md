# add-mini-batch-template-generator-and-quant-swatch-orchestrator

Motivation: reduce time-to-value for cost-safe batching/quantization rollouts by providing opinionated mini-batch templates and a lightweight quantization swatch orchestrator that can be auto-provisioned per workload. This PR introduces a template generator (CLI + backend hooks), a set of curated quantization swatch profiles, and runtime guards + telemetry to evaluate unit economics during canary rollouts. Key goals: 1) make it easy for platform and product teams to try conservative batching/quant profiles without manual tuning, 2) capture unit-econ signals (tokens per USD, p95 latency, quality deltas) during short canaries, and 3) provide safe fallbacks and gradual ramp policies if quality regressions are detected. What changed: new CLI command rwectl econ template generate, a mini-batcher runtime component with three starter templates (conservative, balanced, aggressive), a quantization swatch YAML catalog and merge logic, telemetry events and eval hooks tied to prompt-sets, a short e2e sim harness to sanity-check throughput/latency, and updated console UI to visualize unit-econ deltas. Rollout plan: feature toggled behind econ.templates gate, staged canary to customers with opt-in, metrics-driven rollout using existing rollout controller. Related Linear: ENG-3245 (template generator), ENG-3401 (quant swatch orchestration).
