# Introduce soft-drain regulator and fanout stabilizer to reduce cross-region thrash and preserve SLOs

This PR implements two coordinated reliability features: a Soft-Drain Regulator (SDR) that performs time-windowed, probabilistic admission tapering instead of immediate tenant eviction, and a Fanout Stabilizer that spaces and jitter-controls cross-region rejoin/fanout to prevent synchronized failovers. Motivation: recent incidents (SRE-142, SUP-77) showed abrupt evictions caused KV cache churn and tail-latency spikes during regional overloads. The SDR integrates with the existing circuit state machine to apply a graceful admit_ratio that decays over a configurable window and preserves partial KV continuity; the Fanout Stabilizer introduces a per-region rejoin-window with randomized jitter and an optional tenant backoff multiplier. This reduces oscillation between regions and keeps SLO breach blast-radius small. Key changes: new runtime admission policy implementation, control-plane knobs for per-tenant and per-route soft-drain thresholds, two Prometheus metrics (sdr_admit_ratio, fanout_rejoin_delay_seconds), a canary rollout manifest and migration helper that converts sticky-eviction policies to soft-drain with safe defaults. Testing: unit tests, integration tests against benchmark-lab scenarios, and a staged canary in us-west-2.
