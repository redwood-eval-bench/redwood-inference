# introduce multi-sdk credential probe and async-to-generator adapter for streaming ergonomics

Adds a lightweight, language-agnostic credential probe endpoint and a Python async-to-generator adapter to improve SDK ergonomics and parity across Py/TS/Go. Motivation: many downstream apps still rely on sync generators or simple for-await loops; Python's asyncio generators and TypeScript async-iterables had subtle ergonomic gaps leading to token refresh races and duplicated reauth logic. This PR centralizes a small probe API used by SDKs to validate credential freshness without performing a full request, and introduces an adapter layer so Python consumers can opt-in to generator-style streaming without rewriting asyncio code. Changes include SDK surface updates, telemetry for probe usage, example app updates, and version bumps for each SDK.
