# SDKS: auth mosaic + streaming consolidation and ergonomic API polish

Context: We observed subtle divergence in how Python/TypeScript/Go SDKs handled token refresh during long-lived streams and how retry presets influence stream resume characteristics. This caused two classes of production issues: (1) opaque reauth races that produced 401s during resume, and (2) inconsistent backpressure hints leading to latency spikes when batching heuristics changed across SDKs. This PR introduces a small cross-SDK surface (SessionSurface) and a compact "mosaic" of auth utilities to align behavior. Key goals: harmonize reauth handshake, provide ergonomic retry presets (latency-first and throughput-first), and expose minimal stream backpressure hints to SDK consumers. Changes: - Introduce SessionSurface (py) and SessionFactory (go) as a lightweight facade for long-lived sessions; exported helpers in ts for parity. - Add two retry preset bundles: latency_aware and throughput_aware (shared canonical definitions in pkg/common/retry). - Token choreography: tokenHelper/ensureToken (ts) and a small auth-mosaic helper (py/go) to centralize refresh windows and jitter. - Streaming ergonomics: backpressure hints API (ts) + iterator safety guard (go) + python convenience wrapper for async generators. - Docs & examples: migration guide with concrete recipes for upgrading long-lived streams; example showing how to pick retry presets and combine with SessionSurface. Testing: unit coverage across SDKs; manual smoke runs against a dedicated canary stack. CI: one flaky legacy test in sdks/python was rerun and passed on the second run. Checklist: - [x] API design reviews with SDK leads - [x] Cross-language parity tests - [x] Changelog entries and migration guide - [x] Version bumps for SDK packages (py 1.13.0, ts 1.29.0, go 1.12.2) Rollout plan: merge to main, cut coordinated SDK releases; library consumers that rely on automatic token refresh should switch to the new SessionSurface/Factory or call the token helper from their stream bootstrap code. Related: ENG-2345 (stream reliability), PM-7890 (developer ergonomics).
