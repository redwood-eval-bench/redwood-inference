# credential fallback priority and stream adapter API clarifications (v1.7.0)

Motivation: Several downstream teams reported ambiguous credential precedence and inconsistent streaming event envelopes across SDKs which caused subtle auth edge-cases during long-lived streams and cross-language parity issues. This PR standardizes the TypeScript SDK credential resolution order and clarifies the streaming adapter surface to align with Python and Go ergonomics while remaining backward-compatible via deprecation warnings. Summary of changes: (1) Introduce CredentialProvider interface and deprecate CredentialFactory.create; providers must implement getToken and optional renewToken hooks. (2) Define explicit credential fallback priority: explicit provider passed to client > REDWOOD_API_KEY env var > shared credential chain (user config, cloud metadata) > anonymous. (3) Stream adapter changes: unify envelope types by introducing StreamEvent<T> and StreamSentinel markers for end-of-stream/heartbeat/partial-flush events, and normalize chunk metadata so higher-level consumers (TypedAsyncIterator) can rely on stable typings. (4) Expose a small compatibility shim (createCredentialAdapter) to ease migration from old factories -> new providers. (5) Documentation and changelog updates; bump package to 1.7.0. Compatibility notes: existing code using CredentialFactory.create will get a console warning and a thin shim that adapts the old API; consumers using raw stream chunk shapes should update to StreamEvent<T> to receive sentinel events. Rollout plan: merge to main, publish canary build, run integration smoke tests with py/go SDKs and a staged client app, then publish stable 1.7.0. Testing: unit tests for provider resolution, integration tests against local mock gateway covering token rotation during active streams, and manual verification of cross-language parity harness. CI: initial run hit a flaky test in streaming/integration (race on mock server lifecycle); test was retried and passed on rerun. Docs: API reference updated, migration guide added to docs/migration/ts-1.7.md. Linked work: ENG-1976 (credential unification), ENG-2045 (stream parity checks).
