# econ-delta-reporter-and-cadence-runner: tenant unit-econ delta exporter + scheduled handoff CLI

Motivation: We need an automated, low-friction way to surface per-tenant unit-economic deltas to the econ pipeline for continuous defaults tuning (batching, cache, quant hints) without inducing extra load on serving paths. This PR introduces two pieces: 1) econ-delta-reporter, a small service component that computes delta summaries from existing telemetry (cost, tokens, batch shapes, cache hit rates, latency distributions) and annotates candidate quant/batch hints; 2) cadence-runner, a CLI that schedules/dry-runs/validates delta exports (local dry-run mode for onboarding + cron mode for production handoff). Design: delta computation uses the existing telemetry-rollup store and computes normalized deltas per tenant over a sliding window, attaches metadata and a confidence score, then stores a signed export blob in the econ-exports bucket and emits a handoff event to the econ-inbound topic. The export schema includes: tenant_id, window_start, window_end, aggregate_cost_change_pct, candidate_quant_profile_id (optional), recommended_batch_shape, cache_prefill_ratio_change, confidence_score, sample_trace_refs. Safety: the reporter includes a rule engine that suppresses suggestions if latency regressions or error spikes exceed configured thresholds and will never auto-apply changes; cadence-runner supports a --dry-run and --preview flag and a safe mode that validates exports against the tenant's rollout policy. Checklist: add reporter service + cli, unit/integration tests, telemetry schema migration (non-breaking), docs and runbook, smoke bench with a synthetic tenant. Rollout plan: deploy reporter behind a feature flag, run cadence-runner in dry-run for 2 weeks for top-100 tenants, enable handoff for selected internal customers, then broader opt-in. Related: ENG-1987 (econ inferencing hooks), ENG-2041 (telemetry schema), SUP-4421 (support request to export tenant deltas).
Adds a tenant-level unit economics delta exporter and a lightweight scheduled CLI to ship periodic deltas to the econ service; no customer-facing API changes; enable via tenant defaults or CLI rollout.
