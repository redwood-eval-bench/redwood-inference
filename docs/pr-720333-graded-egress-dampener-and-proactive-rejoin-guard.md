# Introduce graded egress dampener and proactive rejoin guard (hotfix)

Context: Recent incident (SUP-7890) exposed a pathological interaction between regional KV-drain timing and our egress throttles that caused aggressive connection reopens during transient egress pressure, amplifying downstream latency spikes. This PR introduces a graded egress dampener to smooth egress capacity reductions and a proactive rejoin guard to reduce stormy connection re-establishes. Summary of changes: 1) egress/dampener: new graded dampener module that applies a token-bucket backed smoothing window on egress reductions, with decaying step sizes per-tenant so sudden egress caps are ramped over a configurable window (default 30s). 2) recon/probe: proactive rejoin guard that tracks last-closed-epoch per connection and enforces a jittered exponential backoff with a lightweight health probe before allowing full-weighted rejoin; ties into existing lease metadata (prevents churning when upstream regional probes are noisy). 3) telemetry: added telemetry hooks and SLI emitters (egress_dampener_effect, rejoin_backoff_count, rejoin_probe_latency_p50/p95) and an SLO inspection alert rule that surfaces rapid tenant rejoin churn. 4) safety: feature-gated behind runtime flag runtime.features.graded_egress_dampener; default enabled only in regions with high egress variance. Motivation: Smooth, predictable degradation preserves SLOs for high-value tenants by avoiding oscillatory reopen-and-evict cycles that lead to KV mis-synchronization and cascading failovers.
