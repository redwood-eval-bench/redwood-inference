# Provisional profile summary and changelog suggester for fast model onboarding

Motivation: teams onboarding experimental or forked models need a low-friction path to register models and get immediate, actionable release notes so the rest of the platform (serving, billing, console) can surface reasonable defaults. This PR introduces a provisional profile manifest plus a changelog-suggester pipeline that generates concise draft release notes seeded from telemetry, metadata diffs, and a lightweight confidence score. Goals: 1) allow 'quick onboard' flow that requires minimal profiling data, 2) attach a machine-suggested changelog that curators can edit, 3) surface a provenance + confidence tag to guide auto-rollouts. What changed (high level): added a provisional_manifest schema and validator, a background worker that synthesizes suggested changelog bullets from new model metadata and sample telemetry, CLI flags for quick-onboard, and test coverage for the suggester heuristics. Security/safety: the suggester includes a scrubber to remove PII from examples, and all generated notes are opt-in for release publication. Rollout plan: feature-flag gated, opt-in default for internal teams, staged rollout to external users after 2 weeks of telemetry.
