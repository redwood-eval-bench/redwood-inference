# healthwatch: out-of-band detection + deferred load-shed fastfix

Motivation: During a recent regional instability incident we observed aggressive immediate load-shedding decisions that amplified transient probe failures and caused a cascade of tenant degradations. Root cause analysis showed the control-path probe we used for SLO enforcement was tied to the same request path and therefore observed correlated failures during short KV-drain windows and API spikes. This PR introduces an out-of-band (OOB) healthwatch probe and a short-lived deferred-shed state machine to prevent premature circuit flips. In concrete terms this change: 1) Adds an independent healthwatch goroutine that performs lightweight control-plane probes (small RPCs to local runtime control endpoints) and publishes a high-resolution OOB health metric. 2) Implements a deferred_shed decision layer that requires sustained OOB unhealthy state for a configurable window (default 30s) before promoting an aggressive shed action. 3) Exposes a runtime feature flag (deferred_shed_enabled) and a rate-limited manual override in the console for emergency ops. 4) Adds observability: new metrics (oob_probe_latency_ms, oob_unhealthy_seconds, deferred_shed_decision) and structured logs for handoff events. 5) Includes a small hotfix to revert a prior micro-optimization in the circuit evaluator that caused immediate reopen attempts during KV-cache drains. Rollout plan: default feature-flag is enabled in canary region us-west-2 for 2 hours with synthetic traffic (health-check + tenant traffic mix); if metrics show no regressions we will roll forward to us-east-1 and EU regions. Rollback: toggle deferred_shed_enabled=false or revert the feature flag; the revert commit is isolated and small. Tests: unit tests for state transitions, integration test that simulates KV drain + probe failures, and an end-to-end smoke that validates latency SLOs under synthetic spikes. This PR is focused on stability and is intentionally conservative in changes to the runtime hot path. Related: ENG-3241, links to incident notes and the postmortem.
