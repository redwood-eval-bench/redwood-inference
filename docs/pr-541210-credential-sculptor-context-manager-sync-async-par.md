# credential-sculptor: add ContextManager credential injector, sync/async parity wrappers, and stream-chunk decorator

Context and motivation: Teams building streaming integrations reported friction wiring per-request credential refresh logic into both sync and async consumer paths. This PR introduces a lightweight, opt-in credential helper (CredentialSculptor) implemented as a ContextManager/async context manager to reduce ceremony and make per-call credential injection predictable. It also provides a set of parity wrappers so code paths using generator-style streaming do not diverge between sync and async SDK users. Additionally the PR adds a small stream_chunk_decorator that stabilizes streamed byte/chunk boundaries for callers that need deterministic chunk sizes (useful for batching/metrics and deterministic KV cache warmup). All changes are backwards-compatible and guarded behind explicit helpers; no automatic behavioral changes unless the helper is used.
