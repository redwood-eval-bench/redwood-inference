# Introduce drift triage scorer and CI smokehook

Motivation: Our existing CI smoke-evals flag regressions but often produce large, undifferentiated failure sets that are onerous to triage. This PR adds a lightweight drift triage scorer and a CI hook that (1) computes a ranked set of prompt examples per cohort using a CDF-based severity heuristic, (2) surfaces the top-N examples inline in the PR check with token-level diffs, and (3) emits a compact triage payload to the eval service for downstream annotation and paging. Design summary: drift_triage.py implements a cohort-aware scoring function that combines effect-size (A12-style nonparametric score), delta in distributional quantiles, and a novelty penalty to de-prioritize statistically insignificant noise. The CI hook is implemented as .github/workflows/ci_drift_triage.yml and a small GH Check runner that posts annotated examples as check-run annotations. A new test harness in tests/test_drift_triage.py simulates cross-seed instability and verifies the scorer's top-k stability. Docs: docs/triage-playbook.md explains how on-call/triage teams should interpret scores, and how to opt-in or silence the hook for experimental branches. Backwards compatibility and opt-in: the hook is disabled by default; teams can enable it per repo via a top-level ci config flag "enable_drift_triage: true". Security and privacy: the hook redacts sensitive prompt metadata and only sends hashed prompt fingerprints when forwarding to the annotation service. Rollout plan: start as an opt-in beta for platform-owned repos, collect feedback for 2 weeks, then enable for core evaluation CI if noise is acceptable. Test plan: unit tests for scorer, integration test that exercises the GH check annotations, and a small pilot run on historical PRs to compare triage prioritization against manual labels. Implementation notes: prioritized examples include a minimal context snapshot, the baseline and candidate outputs, token-level diff highlights, and a triage_score. This PR also includes a small evaluator shim so existing smokechecks can call into the triage scorer without changing their control flow.
