# cost-garden-batchlet-prefetcher-and-quant-bucketizer

Add tenant-aware micro-batcher (batchlet) and quantization bucketizer; introduce CLI dry-run for cost suggestions; telemetry and docs added.
Context: Customers with bursty micro-traffic and long-tail sequence lengths are seeing unpredictable unit economics because a single global batching + quantization default can't cover both low-latency interactive routes and high-throughput batchy routes. This PR introduces two coordinated pieces: (1) Batchlet prefetcher/controller: a lightweight tenant-aware micro-batcher that selects a small set of candidate batch shapes per-tenant and applies conservative prefix-caching heuristics to reduce per-token cost without violating latency SLOs; (2) Quant Bucketizer: a compact mapping from (model, sequence-length-range, batch-shape) -> quant-profile that lets us pick quantization presets tuned for unit-econ. Motivation: give engineering teams safe, observable defaults that reduce tail cost while enabling rapid rollback and dry-run simulation. High-level changes: - New runtime component batchlet_controller (Go) with policy hooks and telemetry events. - New quant bucketizer service (Python) and a small deterministic registry file (yaml) with candidate profiles (int8/q4/awq-lite). - CLI tool (cost-garden) dry-run mode to simulate tenant traces against chosen batchlet+quant combos and emit estimated unit-econ deltas. - Telemetry: new metrics (batchlet.batch_shapes, quant.bucket_choice, econ.estimated_token_cost_delta) and an e2e smoke test in CI. - Docs: cost-guides/cost-garden.md with rollouts and safety notes. Safety: The controller defaults to conservative batch sizes, always respects tenant latency SLOs, and contains a fast fail-over to previous global defaults if observed retry/error rate increases by >3x in 5m. Rollout plan: feature flag gated; starts as opt-in on Dedicated and Private tenants; CLI dry-run recommended before enabling. Checklist: - [x] Unit tests for batchlet controller and quant bucketizer - [x] e2e smoke test against synthetic burst traces - [x] Telemetry events emitted and wired to ingestion - [x] Docs and rollout guide - [x] Performance microbench on p3 and a100. Related: ENG-3345 (tenant microburst stabilization), SUP-1123 (customer incident investigating cost spikes).
