# hackathon-add-cardboard-llm-prototype-demo

This PR contains a lightweight hackathon prototype called 'Cardboard LLM' intended as a playful demo for the internal hack day. Motivation: build a tiny, self-contained demo that showcases inference pipeline abstractions, streaming output, and an example of an ultra-low-cost edge deployment pattern. The prototype wires together an existing small open model runner (quantized toy model), a tiny local HTTP shim, and a browser-based UI that renders results inside a cardboard-themed mock terminal. Contents: single-page demo UI (static assets + minimal JS), an experiment runner script (scripts/cardboard_run.sh) to start the mini-server, a sample model config under experiments/cardboard/model-config.yaml, and a README with setup steps and safety/disclaimer notes. Not intended for production. Checklist: - [x] demo UI implemented - [x] local runner script + systemd unit example - [x] README with setup and caveats - [ ] follow-up: extract reusable abstractions into runtime/examples. Notes: this PR intentionally keeps changes small and scoped to experiments/ and docs/ so it won't affect main runtime code. It includes a couple of integration test stubs to validate that the demo server starts and responds with expected JSON so CI can exercise the path during the hackathon pipeline. Merge rationale: small, self-contained hackathon artifact merged after light review and green CI.
