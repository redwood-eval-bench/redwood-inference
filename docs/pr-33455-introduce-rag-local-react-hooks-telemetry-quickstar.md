# introduce-local-rag-react-hooks-with-dev-telemetry-quickstart

Add a compact developer quickstart demonstrating a local RAG loop using React hooks, a lightweight in-memory vector store, and an integrated dev telemetry shim. Motivation: developers repeatedly ask for a single-file local pattern that demonstrates streaming RAG, tool-calling hooks, and basic telemetry hooks they can extend for playback or unit testing. This quickstart is intentionally small (one GitHub directory + test harness) and ships: 1) a React client with useRagSession and useStreamingAnswer hooks that show incremental token rendering and cancelation, 2) a tiny Node dev-proxy that emulates Redwood API responses and records telemetry events, 3) an in-memory vector store adapter with an easy-to-read cosine-sim implementation, 4) a Jest e2e test that runs the full stack in-memory. Checklist: - [x] Implement hooks and local app UI - [x] Add dev-proxy with request/response logging and telemetry events - [x] Provide docs/README with step-by-step run instructions and troubleshooting - [x] Include a lightweight prompt set and small sample documents for quick iteration - [x] Add CI job to run unit/test harness on pull requests Notes on safety and scope: this quickstart is for local developer workflows only and intentionally uses non-persistent storage and a mock API key. It demonstrates patterns (streaming, cancelation, reconnects, telemetry event capture) but does not contain production-ready auth, persistence, or SLAs.
