# introduce-observability-notebook-and-token-cost-annotator

Motivation: operators need a single, queryable snapshot that ties traces, metrics and token-level cost for a given invocation so oncall and SRE can do fast RCA without stitching multiple services. This PR introduces the Observability Notebook: a minimal server-side snapshot format and a lightweight UI template that surfaces token_cost slices, per-span enrichments and a prompt-shape baseline. The Notebook is backed by a small "cost baseline store" that keeps per-model/prompt-shape median per-token cost for drift detection. What this PR does: 1) adds an invocation snapshot producer (src/observability/notebook.py) that bundles trace spans, token-cost histogram, KV-cache warmup events, and a compact provenance map; 2) enriches spans with token_bucket_label and token_phase tags (pkg/tracing/enrichers/token_annotator.go); 3) emits token_cost.slice metrics (per-invocation slice) and token_cost.fingerprint from the producer to telemetry (telemetry/metrics_registry.yaml, pubsub/transformers_cost.py); 4) a console dashboard template for quick inspection and drilldown (dashboards/observability-notebook.json) and docs for oncall interactions (docs/observability/notebook.md); 5) feature flag and rollout policy (infra/fflags.yaml) so we can canary the notebook in Dedicated and Hosted; 6) unit tests (tests/test_notebook.py) and small e2e harness adjustments. Backwards compatibility: snapshot producer is behind a flag and uses existing trace/span formats with additive span tags so there are no breaking changes to downstream consumers. Rollout plan: enable 5% of traffic for internal orgs and Dedicated test tenants for 48 hours, collect adoption and retention metrics, then broaden. Link to design doc and demo: Linear ENG-4521 (includes mockups) and a short demo recording attached in comment. Checklist: - [x] library + producer - [x] span annotator - [x] metrics registration - [x] dashboard template - [x] docs and runbook snippet - [x] tests - [x] feature flag and rollback path Observability gains: faster mean-time-to-insight for token-cost anomalies, one-click RCA for long-tail high-cost invocations, and a baseline-driven alert that reduces noisy token-drift pagering by suppressing alerts under baseline-aligned drift. Caveats and limitations: snapshot increases per-invocation metadata footprint; notebook payloads are compressed and retention defaults to 7 days behind the flag. We will iterate on retention and indexing strategies after canary results.
