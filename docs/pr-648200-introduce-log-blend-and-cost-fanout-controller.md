# Introduce log-blend (sampled log snippets) and cost-fanout-controller for query isolation

Motivation: We regularly need short, privacy-safe log snippets joined to sampled traces for SRE debugging and post-incident triage without increasing cardinality or query load. Separately, heavy ad-hoc observability queries are interfering with rollup aggregation queries used by SLO dashboards. This PR introduces two complementary pieces: 1) 'log-blend' — a sampled, de-identified log snippet joiner that attaches a small, fixed-size snippet to sampled trace events using an anchored bloom-hash to avoid high-cardinality joins; 2) 'cost-fanout-controller' — a lightweight query router that routes large aggregation/query windows to a separate read-replica / priority queue and applies soft rate-limits to protect the main telemetry index.
