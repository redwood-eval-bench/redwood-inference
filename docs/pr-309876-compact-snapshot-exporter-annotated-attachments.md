# compact snapshot exporter with annotated attachment packaging

Motivation: responders frequently need a compact, shareable snapshot from an on-call session that includes the minimal telemetry, run metadata, and curated attachments (logs, traces, core snippets) but without PII or large bulk. This PR adds a compact snapshot exporter that serializes incident context into a small, portable archive (manifest.json + compact binary blobs) with optional attachment annotations. Design: exporter produces a gzipped tarball containing: manifest.json (shallow indices, retention tags, sanitized field map), compact-telemetry.ndjson (bounded sample of logs/metrics), kv-run-meta.json (request IDs, timeline markers), and an attachments/ directory with annotated JSON sidecars describing provenance and redaction hints. A sanitization plugin chain runs before packaging to redact PII and strip large payloads; the size budget defaults to 5MB but is configurable per-export. Implementation: adds a new subcommand `incident-bot snapshot export --session <id> --budget 5MB --annotate` and an HTTP admin endpoint POST /internal/snapshots/export that supports streaming upload to S3-compatible backends. The exporter uses the existing telemetry-query module, reuses the oncall ACL checks, and includes optimistic concurrency checks to avoid exporting in-flight ephemeral data. Testing: unit tests for sanitizers, an e2e test that runs against a local test-store, and a smoke test exercising the CLI and HTTP flow. Rollout plan: behind feature flag `compact_snapshot_exporter`; enable for internal staging, bake for one week, then opt-in to broader internal users. Checklist: ensure ACL behavior is identical to current snapshot APIs, verify S3 upload retries, confirm size-budget enforcement, add docs and example CLI calls. Related: reworks parts of ENG-8720 (attachment annotation schema) and references SUP-1289 (support request for smaller evidence bundles).
Adds an on-call snapshot exporter that packages sanitized telemetry, run metadata, and optional annotated attachments into a compact, legacy-compatible archive. Exposes a CLI entrypoint and an HTTP export endpoint. No breaking changes to public APIs.
