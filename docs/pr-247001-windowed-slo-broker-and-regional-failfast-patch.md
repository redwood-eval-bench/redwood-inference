# introduce-windowed-slo-broker-and-regional-failfast-path-hotfix

Context: Recent multi-region incidents showed prolonged SLO violation windows because per-region SLO enforcement lacked a compact coordination layer and the failover path sometimes waited until eviction heuristics were severe. This PR adds a lightweight 'windowed SLO broker' that aggregates short-window SLO pressure signals across local region cohorts and exposes a deterministic failfast decision to the request router so we can open a fast-regional-fail path earlier and avoid cascading queue growth. Motivation: shorten the time between a meaningful SLO breach in a region and safe, observable failover to adjacent capacity while preserving KV cache affinity where possible. Summary of changes: 1) control/windowed_slo_broker.go: new broker that consumes per-tenant short-window metrics (p95 latency, error_rate, queued_requests) and produces a single epoch-aligned decision token (NORMAL | SOFT_SHELF | FAILFAST). The broker implements exponential decay windowing and tenant-weighted aggregation. 2) router/failfast_integration.go: integrates the broker token into the existing smart-routing policy; when token==FAILFAST the router triggers an immediate prioritized egress to fallback regions and tags requests with "slo-trigger" for observability. 3) kv/preserve_on_failover.go: hotfix to preserve most-recent KV prefixes during transparent failover (avoids full cache flush for live sessions). 4) telemetry/slo_events_v2: new telemetry event + annotations to make trigger windows visible in console. 5) tests: unit + integration harness updates and a small synthetic canary to validate behavior under patient spike scenarios. Rollout plan: staged feature-flag rollout starting with internal Dedicated clusters -> opt-in beta tenants -> full rollout across hosted regions after 72 hours of telemetry validation. Backout mechanism available (feature flag + router fallback to previous behavior). Performance notes: local microbench harness shows median decision latency for the broker < 1.8ms at 99th percentile of 1000 tenants; synthetic canary shows ~18% reduction in sustained queue depth under the same egress capacity compared to prior logic.
