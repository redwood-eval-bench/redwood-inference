# Dynamic burn-rate alerts and compact SLO telemetry index for token-cost profiles

Motivation: reduce noisy SLO alerts caused by high-volume low-cost token spikes and lower tracing cardinality while preserving actionable token-level cost/latency signal. This PR introduces two complementary pieces: 1) a compact SLO telemetry index that materializes rolling summaries per-tenant and per-route using epochal aggregation to bound cardinality; 2) dynamic burn-rate alert rules that weight burn by token-cost profiles (not just request count) so tenants with expensive tokens produce proportional alerts. Changes include runtime instrumentation, aggregator logic, dashboard widgets, CI tests, and alert policy updates.
