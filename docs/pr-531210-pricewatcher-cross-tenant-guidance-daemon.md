# Introduce pricewatcher daemon for cross-tenant cost guidance and safe autoscaling defaults

Motivation: teams repeatedly ask for guardrails that translate tenant-level usage into safe autoscaling and batching/caching defaults. This daemon (pricewatcher) continuously aggregates anonymized per-tenant token/latency/cost signals, surfaces candidate default profiles (batch size, prefill window, quant profile class), and emits non-blocking recommendations to the defaults service and to cost-alerting. The goal is automated, conservative suggestions rather than unilateral changes. Key features: 1) streaming aggregator built on existing telemetry pipeline (uses sample-based sketch to bound memory), 2) rule engine that maps signal patterns to candidate defaults (safe-first fallback logic), 3) tenant scoring and cooldowns to avoid oscillation, 4) a dry-run mode and CLI to preview suggested defaults, 5) lightweight opt-out annotation for enterprise tenants. Backwards compatibility: pricewatcher only writes suggestions to the new /defaults-suggestions API; it does not change live routing or model configs. Rollout plan: feature gated by tenant and org-level flags, initial rollout to internal canaries then to low-volume tenants, followed by evaluation against control cohort for 2 weeks. Observability: added metrics for decisions emitted, suggestion acceptance rate, and cooldown events; traces link suggestion -> defaults-service decision -> applied default. Security/data: aggregated signals are anonymized and sampled; no PII or prompt contents are stored. Checklist: - [x] daemon service implementation + unit tests - [x] rule-engine DSL + conformance tests - [x] defaults-suggestions API server + schema v1 - [x] CLI preview + dry-run - [x] e2e smoke with canary tenant - [x] docs and runbook - [x] canary rollout config in infra. Migration notes: default profile versions are immutable; when a suggestion is accepted the defaults service produces a new profile revision. Operators can manually revert or pin older revisions. Related: builds on ENG-2981 telemetry sampling, pairs with ENG-3050 defaults-as-code work.
