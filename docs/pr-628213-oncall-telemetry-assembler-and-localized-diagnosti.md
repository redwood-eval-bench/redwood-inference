# oncall telemetry assembler and localized diagnostics

Context: Oncall responders often need a compact, privacy-safe telemetry bundle that highlights the most relevant traces, logs, and metric deltas for an alert. Motivation: Reduce time-to-diagnosis by assembling a localized diagnostics package (LDP) automatically when an alert is claimed, and attach it to the incident thread. This PR adds an LDP assembler in incident-bot that: 1) captures lightweight trace excerpts (span sampling), 2) computes metric and SLO delta summaries, 3) extracts top-3 anomalous logs using a relevance scorer, 4) scrubs credentials/PII with the existing sanitizer, and 5) packages everything as a signed artifact that can be previewed in Slack or downloaded via the console. Changes: - new package incident_bot/ldp with assembler, sanitizer adapters, and upload client - API endpoint POST /ldp/generate (internal) used by oncall claim hook - CLI tool bin/ldp-cli for local repro and sandbox generation - UI preview: slack block generator and small HTML preview renderer - unit and integration tests plus an end-to-end test fixture that simulates a noisy latency alert - telemetry: adds ldp.created and ldp.fetch metrics and tracing spans Backwards compatibility and safety: feature is off by default and behind feature flag incident_ldp.enabled; generated bundles are ephemeral (TTL 24h) and encrypted with team key; sanitizer has an allowlist and denylist that were reviewed by Security. Rollout plan: enable for SRE teams only for 2 weeks, collect feedback, then expand to all oncall rotations. Rollback: flip feature flag to false to stop generation and revoke existing pre-signed URLs.
