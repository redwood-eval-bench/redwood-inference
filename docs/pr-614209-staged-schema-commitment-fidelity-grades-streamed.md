# Staged schema commitment and fidelity grades for streamed toolcalls

Motivation: production LLMs perform tool/function calls where structured output must be validated; strict immediate schema enforcement during token streaming causes frequent early rejects (esp. for multi-step toolcall handoffs) and harms latency. This PR introduces a staged commitment model for JSON-schema style response_format where enforcement has graded fidelity levels and a distinct commit phase for toolcall-delimited streams. Goals: (1) allow the model to produce partially-formed structured output during streaming without triggering hard rejection; (2) provide a post-toolcall validation step that can accept/coerce or surface actionable errors with fine-grained error taxonomies; (3) keep OpenAI-compat layer semantics consistent (response_format remains the canonical hint) while adding backward-compatible flags for strictness grading.
Implements staged schema commitment with three fidelity grades (permissive, graded-verify, strict-commit), streaming checkpoints that mark schema anchor points, and a post-toolcall commit/verification phase. Adds OpenAI-compat mapping for new response_format hints and SDK helpers for negotiating fidelity levels.
