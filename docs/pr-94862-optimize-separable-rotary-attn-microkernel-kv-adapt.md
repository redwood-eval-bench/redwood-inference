# Separable rotary microkernel + KV-adaptive continuous batcher

Summary: Introduces a separable-rotary microkernel that isolates rotary application from q/k/v transforms and a KV-adaptive continuous batcher that widens batching windows when prefix-hit probability is high. Motivation: production p99 latency for short chat turns; profiling showed general-purpose kernels and static batching were inefficient. Key changes: new CUDA microkernel with lane-aligned loads and small unrolls for common head sizes; deterministic rotary offset clamps; cache_manager API extension to report ring hit estimates; batcher policy that adapts per-route based on observed KV prefix-hit-rate and sequence variance; microbench harness and regression tests. Benchmarks: short sequences (8-32 tokens) throughput +24% and p99 -18%; medium (64-128) throughput +12% and p99 -9%; long sequences (512) negligible change. CI: unit and integration pass; perf microbench passed after pinning GPU CI image. Merge: squashed into main on 2026-02-22. Rollout notes: enable in Dedicated pools at 25% traffic first; dashboards and alerts added for batcher.window_size and kv.cache.prefix_hit_rate. Risks: rotary/rope mixing edge-cases handled with defensive clamps and tests; adaptive batching affects scheduling so rollout gating recommended.
Adds a separable rotary attention microkernel and an adaptive continuous batcher that uses KV prefix-hit heuristics. Improves short-turn throughput and p99 latency; no API changes.
