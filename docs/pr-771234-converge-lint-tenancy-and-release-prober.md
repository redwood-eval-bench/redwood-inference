# Converge lint tenancy, integrate dependency-graph pruner, and add lightweight release prober

Motivation: our presubmit lint and release smoke steps have grown brittle and slow as we onboard per-service lint rules and when lockfile churn increases CI runtime. This PR consolidates three related efforts into a single, cohesive change: (1) lint tenancy: route lint jobs per-package using a lightweight tenancy layer so teams can opt into stricter profiles without blowing up global CI, (2) dependency-graph pruner: a tool that computes minimal impacted graph for node/go/rust changes and prunes integration/test targets in the presubmit matrix, and (3) lightweight release prober: a small, fast post-release smoke job that validates artifact integrity and a subset of runtime hooks in the staging channel. Summary of changes: added a tenancy-aware lint router that reads .ci/tenancy.yaml and selects lint profiles at workspace scope; factored lint executors into a small Go micro-binary (tools/ci/lint-router) to avoid shell complexity; introduced tools/dep-pruner which computes affected targets via git + dependency manifests and emits a PR-specific target set used by the presubmit generator; added .github/workflows/release-prober.yml plus a tiny prober script scripts/release/prober.sh that runs a canonical smoke sequence against staged images; updated the presubmit generation template to accept an optional ci:pruned-targets artifact; added docs at docs/ci/tenancy.md and docs/ci/dep-pruner.md. Checklist: - [x] lint router + tenancy config parser - [x] dep-pruner prototype + unit tests - [x] integrate pruner output into presubmit template - [x] release prober workflow + smoke script - [x] docs and migration notes - [x] staged rollout (feature flag via .github/ci-opts) Tests & validation: unit tests for the Go components; end-to-end run in the integration CI project using a synthetic small repo; canary rollout to 10% of presubmit runs for 48 hours before full flip. Rollout plan: enable tenancy mode behind a CI opt-in flag and roll dep-pruner as an additive optimization. If any flakes arise, teams can opt-out per-repo by setting tenancy: disabled in .ci/tenancy.yaml. Release notes: Improve CI feedback by reducing presubmit runtime for typical small changes and letting teams opt into stricter lint profiles. Add a post-release smoke prober to catch artifact regressions earlier.
