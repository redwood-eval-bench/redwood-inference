# Introduce jurisdictional operator claims, KMS proxy with region affinity, and audit canonicalizer

Motivation: operator-initiated requests that used fallback KMS routes could violate tenant residency expectations in multi-geozone deployments. This PR introduces a lightweight KMS proxy with region-affinity routing and a jurisdictional operator-claim propagation middleware that ties RBAC v2 decisions to geozone claims. It also adds an audit header canonicalizer to ensure consistent downstream proofs for compliance ingestion. Changes include a claim backfill migration for existing operator sessions and telemetry for residency decision sampling.
