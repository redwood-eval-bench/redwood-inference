# introduce-tenant-surge-dribble-and-epochal-handoff-protector

Adds a staged tenant surrender mechanism and ephemeral egress fuse to make regional failovers less noisy and reduce SLO oscillations. Exposes two new telemetry counters and a small config knob for surge-dribble window length.
Motivation: During regional overload and coordinated failovers we've observed cascading evictions where tenants are fully discharged then aggressively re-admitted causing SLO oscillations and KV cache churn. This change introduces a 'surge dribble' admission path and an epochal handoff protector that preserves short-term reservation credits and prevents immediate aggressive rejoin. Design: 1) Staged tenant surrender: when a node decides to shed tenant traffic it first enters a dribble phase where admission is throttled to a low steady rate while KV cache is preserved for a configurable window. 2) Epochal handoff protector: the node attaches an epoch token to surrendered tenants; downstream nodes defer hard-eviction for the token TTL and apply an exponentially decaying reservation credit to prioritize graceful rejoin. 3) Ephemeral egress fuse: a configurable per-region egress cap that will soft-deny new allocations when the region-wide egress budget is saturated; the fuse emits detailed telemetry that feeds the Console to explain soft-denies. Backwards compatibility: tokens are opt-in per deployment via runtime flags for Dedicated/Private. Metrics: tenant.surge.dribble_rate, tenant.surge.reservation_tokens_issued, tenant.surge.epoch_rejoins.
