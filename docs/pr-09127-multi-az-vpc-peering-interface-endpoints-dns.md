# Multi-AZ VPC peering, interface endpoints and Route53 DNS forwarding for Private Control Plane

Motivation: Customers running Redwood Private in customer VPCs require a resilient control-plane connectivity pattern that supports multi-AZ private endpoints, cross-account peering, and DNS forwarding without exposing control plane services to the internet. This PR implements Terraform modules and Helm hooks in the private-installer to provision: 1) dedicated subnets per AZ for control-plane interface endpoints, 2) AWS Interface VPC Endpoints (VPCE) for SSM/EC2/SecretsManager/KMS used by the control plane, 3) cross-account VPC peering with optional route table propagation and security-group restrictions, 4) automated Route53 inbound/outbound endpoints and conditional forwarding rules so control plane hostnames resolve across peered VPCs, and 5) tight security group templates and example least-privilege IAM policies. Changes are split into small commits and include an at-scale test harness used in our perf-canary cluster. Added optional VPC control plane module enabling multi-AZ interface endpoints, cross-account VPC peering helpers, Route53 inbound/outbound endpoints and conditional forwarding templates. Defaults are opt-in; see docs/examples/customer-vpc.md for migration steps and rollback guidance.
Operator notes: To enable, set installer.use_control_plane_module=true and provide control_plane_peering_config with peer_account_id and peer_vpc_id. The module will create route entries; if you manage routes centrally, set manage_routes=false. When tearing down, run 'terraform plan' to see dependent resources; Route53 inbound endpoints can take up to 30 minutes to become available, and peering teardown requires route cleanup first.
Security review completed by infra-security team: recommended KMS key policy adjustments for cross-account SecretsManager access and explicit IAM conditions for SSM. Applied least-privilege templates; flagged one follow-up to rotate installer-managed KMS keys to customer-managed keys in a future PR.
