# Introduce small-batch heuristic auditor and quant safety adapter

Add a lightweight auditing tool that scans tenant prefill and batching defaults and emits safe quantization fallback rules. Includes a small CLI and telemetry events to integrate with Console alerts.
Motivation: Some tenants with low qps and narrow request distributions were picking aggressive default batch shapes and quant profiles that regressed latency and occasionally broke low-memory hosts. This PR adds a lightweight auditor and runtime adapter that (1) statically lints tenant prefill/batching defaults against observed shape histograms, (2) synthesizes conservative quantization safety fallbacks for affected tenants, and (3) surfaces deterministic telemetry so Console can create alerts and automated rollbacks. What changed: added a new CLI 'prefill-lint' under cmd/prefill-lint for offline checks; implemented runtime adapter in serving/prefill/safety_adapter.go that applies conservative quant/shape overrides when memory headroom is low; added a small telemetry bridge (observability/prefill_audit_bridge.go) that emits audit findings as events; extended the defaults manifest schema with an optional safety_profile block; unit/integration tests and docs. Checklist: - [x] Design doc reviewed (ENG-4921) - [x] Unit tests for linter and adapter - [x] Integration smoke against a small local cluster - [x] Telemetry hooks added to Console-compatible channel - [x] Backwards compatible: new safety_profile is optional Rollout plan: Canary rollout on dedicated pools for 48h; observe telemetry and Console alerts; if we see >5% latency regression on pinned tenants revert adapter via feature flag.
