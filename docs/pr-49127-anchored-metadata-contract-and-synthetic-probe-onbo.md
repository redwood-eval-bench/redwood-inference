# Introduce anchored metadata contract and synthetic-probe onboarding hook

Context: Onboarding has become brittle for large models because metadata variance hides regressions in perf/size tradeoffs. Motivation: provide a compact, anchored metadata contract that makes profile expectations explicit and a lightweight synthetic-probe harness that validates those expectations during onboard and in CI. What this PR does: 1) Adds an anchored metadata schema (schemas/anchored_metadata.schema.yaml) that requires an explicit 'anchors' section with representative input-size buckets and expected token-per-ms ranges; 2) Adds a synthetic probe runner (onboard/hooks/synthetic_probe_runner.py) that spins up a cached/local inference harness to run sampled microbenchmarks against anchors and emits an onboarding verdict; 3) Adds a migration script (scripts/migrate/annotate-existing-profiles.py) to backfill anchors for legacy profiles using size heuristics and sampled telemetry; 4) Wires autodraft changelog seeds (changelog/autodraft_seeds.py) to include probe snapshots and anchor diffs; 5) Adds developer docs (docs/onboarding/anchored-contract.md) and unit/regression tests (onboard/tests/test_probe_harness.py). Rollout plan: land behind feature flag onboarding.anchored_contract; run migration with --dry-run then --apply; enable probe checks in the nightly onboard CI. Checklist: - schema drafted and validated; - synthetic probe implementation and unit tests; - migration script with dry-run; - docs + release notes; - CI workflow updated. Testing: added unit tests and end-to-end CI job on a small GPU runner; ran migration dry-run against staging model bucket and reconciled size_class assignments. Related work: builds on ENG-5012 (profile staleness detection) and ENG-5120 (onboard automation). Notes: this is intentionally conservative, feature gated, and non-breaking for existing consumers. Manual steps for ops: run scripts/migrate/annotate-existing-profiles.py --staging --dry-run then review report and run with --apply. References: Linear ENG-5012 ENG-5120 and support ticket SUP-3124.
