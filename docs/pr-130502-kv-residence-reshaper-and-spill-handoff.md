# KV residence reshaper and selective spill-handoff to reduce fragmentation-driven evictions

Motivation: under multi-tenant bursty workloads we observed repeated small-page evictions caused by fragmentation and poor spill granularity. These evictions increase CPU and PCIe churn and spike tail latency. This PR introduces the 'Residence Reshaper' — a lightweight in-memory optimizer that periodically rebuckets resident KV pages to improve spatial locality and a selective spill-handoff protocol that prefers coalesced spill targets (cold-store or local fast-disk) when eviction is unavoidable. Changes are behind a runtime feature flag and include telemetry to validate safety. High level: 1) a low-overhead rebucketing pass that reassigns small scattered cache slots into contiguous slots within the same tenant working set, 2) a spill-handoff coordinator that defers single-page spills in favor of a coalesced spill window, 3) eviction scoring updates that penalize fragmentation contribution and favor hot-prefix retention, 4) scheduling changes so rebucketing runs opportunistically during idle cycles and cooperates with the continuous-batching scheduler to avoid interfering with latency SLOs. Implementation notes: the reshaper operates on 'page runs' (variable-length contiguous runs) and uses a lightweight bitmap snapshot to plan moves; moves are pread/pwrite-free within the KV arena (pointer updates) where possible and fall back to copy-on-write for shared pages. The spill-handoff uses a small write-behind buffer to coalesce victims for batch writes and a token-bucket to avoid saturating burst spill bandwidth. Testing: unit tests for allocator invariants and integrated simulation harness covering adversarial fragmentation patterns. Benchmarking: microbenchmarks and a 3-node canary under synthesized mixed-read/write workloads included below. Rollout plan: canary on 10% of traffic, monitor eviction_rate, 95p latency, and PCIe utilization; automatic rollback if eviction_rate increases or 95p latency regresses >5%. Related: builds on prior allocator refactors (ENG-3621) and eviction telemetry work (ENG-4102).
