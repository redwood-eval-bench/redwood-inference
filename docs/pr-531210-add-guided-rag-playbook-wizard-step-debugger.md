# Add guided RAG playbook wizard + step debugger for quick authoring

Context: Developer onboarding for RAG authoring often involves multiple scattered examples (playbooks, agents, tooling). This PR introduces a guided RAG Playbook Wizard and a lightweight step debugger to help engineers compose, iterate, and validate retrieval-augmented generation pipelines quickly. Motivation: reduce ramp time for new users, provide reproducible templates, and surface telemetry-friendly probes to tie evaluation back to Redwood Optimize. What this PR delivers: 1) An interactive CLI-driven wizard (examples/wizard/cli) that scaffolds a RAG playbook with choices for retrieval backend (vectorstore adapters stubbed), chunking strategy, and agent tool bindings. 2) A browser-based step debugger (examples/wizard/debugger-web) that replays a single RAG session with inline traces for retrieval hits, prompt templates, token counts, and matching documents. 3) Four ready-to-run templates: minimal-node-rest, python-async-worker, serverless-edge, and local-ssr-middleware. 4) Devcontainer and CI smoke harness (examples/wizard/.devcontainer, .github/workflows/wizard-smoke.yml) to make the quickstart truly one-click. 5) Telemetry probes and example evals that emit structured events compatible with the Redwood Console ingestion schema (examples/wizard/probes). 6) New docs page and consolidated quickstart (docs/rag-playbook-wizard.md) with migration notes and troubleshooting. Implementation notes: CLI implemented in TypeScript and ships with templates that use the existing SDK calls; debugger is a small React app that consumes a recorded session JSON and maps trace events to UI. Security: templates default to using the Redwood sandbox API key env var and include a note about replacing with dedicated keys for production. Testing: added unit tests for scaffolding logic and an end-to-end smoke test that runs the minimal template against the emulator. Backwards compatibility: no breaking changes to SDK APIs. Migration: none needed for existing examples. Related work: follows patterns from ENG-7219 (playbook standardization) and references prior quickstarts.
